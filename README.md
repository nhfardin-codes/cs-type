## ⚡ Overview

CSType is a professional-grade typing practice application designed specifically for Computer Science students, programmers, and mechanical keyboard enthusiasts. Instead of generic sentences, it challenges you with C programming syntax, Ubuntu terminal commands, and core computer science concepts. 

Featuring strict letter-by-letter tracking and custom audio playback with dynamic pitch randomization, CSType provides deeply satisfying auditory feedback that mimics the crisp clicks and heavy thocks of high-end mechanical switches.

## ✨ Features

*   **Strict Pro-Tracking:** A Typing.com-style engine that tracks your progress letter-by-letter, forcing spacebar accuracy and allowing backspace corrections.
*   **Tactile Audio Feedback:** Powered by HTML5 Audio with dynamic pitch variance (`playbackRate`) to emulate a natural mechanical keyboard sound profile.
*   **CS-Themed Text Pool:** Practice typing what you actually code. Includes C syntax, OS architecture facts, Linux network commands, and more.
*   **Persistent High Scores:** Automatically saves your highest Words Per Minute (WPM) using local browser storage.
*   **Developer Aesthetic:** A gorgeous, minimalist dark-mode UI built with Tailwind CSS and the *JetBrains Mono* font.
